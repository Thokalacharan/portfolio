## ⚡ Local Development & Preview

Because this project is built with standard web technologies, no heavy build tools or npm installations are strictly required to view the site:

### Method 1: Python Local Server (Recommended)
Run in PowerShell / Terminal:
```bash
python -m http.server 3000
```
Then navigate to: `http://localhost:3000`

### Method 2: VS Code Live Server
1. Install the "Live Server" extension in VS Code.
2. Right click on `index.html` and select **"Open with Live Server"**.

### Method 3: Direct File Opening
Double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox, Safari).

## 🚀 Deployment to Vercel

The portfolio is structured for direct, zero-configuration deployment to [Vercel](https://vercel.com):

1. **Via Vercel CLI:**
   ```bash
   npx vercel
   ```
2. **Via GitHub Integration:**
   - Push your changes to the `main` branch of `https://github.com/Thokalacharan/portfolio`.
   - Vercel automatically detects static HTML/CSS/JS and publishes the update to your live URL (`portfolio-three-blue-81.vercel.app`).
